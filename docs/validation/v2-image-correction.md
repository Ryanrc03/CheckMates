# V2-A 动态图片校正验证记录

日期：2026-09-28 至 29。开发分支：`feat/v2-image-first`。为避免公开已回滚的旧 V2 实验提交，发布分支 `release/v2-image-first` 从远端 MVP `cc06071` 开始，仅摘取经 review 的 V2-A 实现与设计。已推送 GitHub `main@c8a34f8` 并部署到 [CheckMates](https://checkmates-pi.vercel.app)。

## 本阶段交付

- 上传照片后先进入调整页，用户确认后 OCR 才读取校正后的图片。每张照片独立分析，不沿用上一张照片的角度和四角。
- 浏览器 Worker 分析最多 1024×1024 的缩略图，给出平面内倾角与保守的纸张四角建议。无可靠边界时保留整张照片；旋转纸张无法安全用水平纸边拟合时不自动裁剪。
- 原图与校正预览并排展示；用户可以拖动四角、键盘移动四角、微调角度、旋转 90°、使用原图或重置。确认后从源图按相同参数导出，最多 600 万像素。
- 更换照片重置调整状态；放弃替换照片保留旧图及已编辑价格；重新识别已有草稿前继续提示替换。
- 同一张照片重新打开时保留四角、角度和 90° 方向；替换照片的识别失败或取消不会清空旧草稿，成功后保留已有参与者。预览尚未更新到当前参数时不能确认。
- 现有 Tesseract 引擎和收费解析未在 V2-A 修改。翻译、结果可视化和 V2-B 的菜品解析未接入。

## 可复核的样本结果

| 输入 | 自动分析 | 确认后观察 |
| --- | --- | --- |
| 项目合成小票 `clear-diner.png` | 判定基本正向，无强行裁剪 | Burger $14.95、Fries $5.95、Lemonade $3.50；原有 OCR 浏览器回归通过 |
| 同图经浏览器生成的 13.4° 倾斜变体 | 独立估计在 12–15° 范围；自动纠偏 | Burger $14.95 保持可识别；浏览器用例通过 |
| 人工生成的暗背景梯形纸张 | 给出可见四角建议 | 可进入四角调整；几何测试覆盖纸张底边不裁切 |
| 项目脱敏衍生小票 | 给出纸张边界建议 | 六个菜品行价格均可读，但菜名仍有 OCR 错字；税被读为 **$5.08**，票面是 **$5.98**，必须人工核对 |
| 模糊图、无清晰纸边白底图 | 返回“不确定”或只给角度建议 | 可保留原图继续、重拍或手动录入 |

上表的复杂小票是生成式遮盖的衍生图，不是未重绘实拍。倾斜和梯形案例由既有样本或程序生成，不能当作独立真实照片准确率。税额错读说明图片校正还不能替代下一阶段的金额分类与复核；本阶段不声称菜品准确识别已完成。

## 仍需完成的验收

- 尚无真实 iPhone Safari 与 Android Chrome 的拍照、拖角、取消及内存/耗时记录；桌面 Chromium 和 375px 模拟视口不能替代物理设备验收。
- 缺少至少 10 张未重绘真实小票与不同版式留出集。自动边界建议仅在少量合成/衍生图片上验证，不能报告真实照片成功率。
- 当前检测只对有明显亮纸/暗背景的纸张给出自动四角；边缘缺失、曲面折皱、重阴影和低对比背景可能需要用户拖动四角或保留原图。
- 高分辨率透视采样仍在浏览器主线程执行。桌面测试未发现回归，但尚未测量真实手机上的拖角响应、导出耗时与内存峰值；这些是发布前验收项。
- OCR 仍使用 MVP 解析。脱敏衍生图存在菜名错字与税额错读；这些属于 V2-B 的目标，当前用户必须复核。

本机 demo：`http://127.0.0.1:3201`。该地址运行工作区的生产构建，仅在本机服务进程存活时可访问。批准的 MVP 仍可通过 `http://127.0.0.1:3200` 对照。下一阶段工作见[设计中的 V2-B](../superpowers/specs/2026-09-28-checkmates-v2-image-first-design.md)。
